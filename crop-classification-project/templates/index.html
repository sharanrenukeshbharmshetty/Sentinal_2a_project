About

Project Overview

This project implements a Deep Learning Approach for Multi Crop Classification using Satellite Images. It leverages machine learning to identify crop types from remote sensing data.

The system processes Sentinel-2 satellite imagery through an image preprocessing pipeline using OpenCV, extracts spectral features, and applies trained models.
